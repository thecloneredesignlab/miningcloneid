# Doxorubicin Nullisomy Model Audit

This note documents the current exploratory standalone nullisomy-only model in [doxo_nullisomy_fit.R](/Users/4470246/Repositories/miningcloneid/code/doxo_nullisomy_fit.R:1). It is not integrated into the main `O2_supply_demand_MAP` optimizer path.

## Assay protocol and observation-model assumptions

Intended assay protocol assumptions for fitting:

- cells were seeded at `3,000` cells/well in 96-well plates
- cells attached/grew for `24 h` before treatment
- treatment time `t = 0` is defined at drug addition, not at seeding
- CellTiter-Glo viability was measured after `96 h = 4 days` of treatment exposure
- the fitted endpoint observable should be viable burden at `4 days` under dose `C`, divided by viable burden at `4 days` under `0 uM` for the same sample
- raw assay values should be interpreted as CellTiter-Glo viability signal, not literal cell counts
- the current first-pass approximation is that CTG signal is proportional to viable cell number

Current fitter audit against those assumptions:

1. Treatment start at `t = 0`:
   `Yes.` The standalone fitter calls the active backend with `treat_day = 0.0`, so treatment begins at simulation time zero, which corresponds to drug addition rather than seeding time.
2. Exact `96 h / 4 day` exposure:
   `Not enforced.` The current fitter still treats `assay_days` as a fitted parameter. It defaults to `6.0` days and the first fit estimated about `4.256` days, so the implementation is close to but not exactly constrained to `4.0` days.
3. Normalized response definition:
   `Yes.` The script predicts normalized response as simulated viable burden under dose `C` divided by simulated viable burden under `0 uM` for the same sample at the same simulated endpoint.
4. CTG interpretation:
   `Partially correct, but under-documented before this audit.` The fitter uses the normalized endpoint fields `mean_normalized_to_0uM` and `sd_normalized_to_0uM`, so it does not directly fit literal raw counts. However, the JSON still contains fields named `raw_count` / `mean_raw_count`, and the script’s observable is viable burden rather than an explicit CTG signal model. The current model therefore assumes CTG signal is proportional to viable cell number.

## `p_mis` definition

In the standalone doxorubicin model, the per-chromosome-copy missegregation probability is

`p_mis(C) = p_mis_base + p_mis_doxo_max * C^n / (EC50^n + C^n)`

where:

- `C` is doxorubicin dose in `uM`
- `p_mis_base` is the baseline per-copy missegregation probability
- `p_mis_doxo_max` is the maximum doxorubicin-driven increment above baseline
- `EC50` is the half-maximal dose
- `n` is the Hill coefficient

The script passes this value into the active C++ backend through `p_const`, so each chromosome copy independently missegregates with probability `p_mis(C)` at each division.

## Why `p_mis_doxo_max ~= 0.805` is likely implausible

The first shared fit pushed `p_mis_doxo_max` to about `0.805`. Since `p_mis` is defined per chromosome copy per division, that implies that at high dose roughly `80%` of chromosome copies missegregate in a single division event.

That is likely biologically implausible because:

- it is close to catastrophic mitotic failure rather than a moderate stress-induced shift in chromosome segregation fidelity
- for cells with chromosome totals near `90-100`, it implies on the order of `70-80` missegregated copies per division
- the fit still remains poor even after moving into that extreme regime, so the large value is functioning more like a compensatory parameter than a credible biological estimate

## Direct death terms after setting `mu_hp = 0`

No direct live-cell death term remains active in this standalone fit path.

Specifically:

- `mu_hp = 0` forces the hypoxia-linked direct death term `mu_eff` to zero
- `fit_treatment = FALSE`, `alpha = 0`, and `tx_mult_min = 1` disable the treatment multiplier pathway
- `dead_buffer` inflow still occurs through nonviable daughter mass generated by the existing nullisomy/buffering kernel
- `k_clear` only clears already-dead compartments and does not directly remove live cells

So live-cell loss in this exploratory model occurs only through division-coupled nullisomy/nonviable offspring mass, not through any separate continuous death hazard.

## Identifiability from normalized viability alone

Normalized viability alone is not sufficient to uniquely identify nullisomy-driven death versus reduced growth or delayed cytotoxicity.

Reasons:

- the observation is a single normalized viable-burden readout across dose, not a direct measurement of missegregation or nullisomy
- a drop in normalized viability can arise from fewer divisions, slower growth, delayed division, direct death, or nullisomy-linked nonviability
- several of those mechanisms can produce similar endpoint dose-response curves after normalization to `0 uM`
- without orthogonal measurements such as time-course burden, mitotic error readouts, dead-cell fractions, or karyotype shifts after treatment, the nullisomy-only mechanism is weakly identified

That means this standalone fit is best interpreted as an adequacy test or negative control for the nullisomy-only hypothesis, not as a uniquely identified mechanistic estimate.

## Current discrepancies to keep in mind

- The standalone fitter currently starts treatment at the correct time origin (`t = 0` at drug addition).
- It currently computes the normalized endpoint in the intended way.
- It does `not` currently enforce the assay’s exact `4 day` duration, because `assay_days` is still free.
- It currently uses viable burden as a proxy for CellTiter-Glo signal, which is an explicit approximation rather than a calibrated assay-readout model.
