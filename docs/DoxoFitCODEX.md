You are working in this repository and have access to the code and data. Your task is to modify the existing ploidy-evolution / oxygen-supply-demand model so that it can be fit to doxorubicin response data with matched karyotype-derived ploidy.

Scientific goal:
We want to test a simplified doxorubicin-specific module in which doxorubicin increases chromosome missegregation, and cell death arises only through nullisomy / nonviable missegregation outcomes. This is intended as a modular alternative to the current oxygen/death-driven missegregation coupling.

Assumptions for this implementation:
1. Use the existing model’s unit for missegregation probability: per-chromosome-copy missegregation probability.
2. Doxorubicin dose should control missegregation through a Hill function:
   p_mis(C) = p_mis_base + p_mis_doxo_max * C^n / (EC50^n + C^n)
   where C is doxorubicin dose in µM.
3. Death should be solely through nullisomy / buffer-drop events generated by the missegregation kernel.
4. Set direct continuous hypoxia/death terms to zero for this fitting mode.
5. For the SNU-668 R2 sample, assume the entire population is high-ploidy: initialize it using cells with chromosome_total >= 90, or equivalently use an initial state concentrated around N ≈ 90 if the empirical distribution is too sparse.
6. Do not recompute ploidy from original .sps.cbs files if the JSON already contains `cell_ploidy`; use stored chromosome_total values.

B. Add a doxorubicin fitting mode
Implement a clean switch, e.g. `mode = "doxorubicin_nullisomy"` or equivalent config flag.

In this mode:
1. Ignore oxygen as a driver of missegregation.
2. Set direct continuous death to zero:
   mu_eff(N, ...) = 0
3. Compute p_mis from doxorubicin dose using the Hill function above.
4. Use the existing per-chromosome-copy missegregation kernel with this p_mis.
5. Route nonviable outcomes through the existing nullisomy / buffer-drop mechanism.
6. Preserve the existing model behavior in all other modes.

Predicted response should be:
predicted viable burden at dose C / predicted viable burden at dose 0

Use a log-scale or Gaussian likelihood appropriate for normalized viability. Make the choice explicit.

F. Parameters to fit

2. EC50
3. Hill coefficient n
4. optionally baseline proliferation / number of effective divisions during assay, if not already fixed

Important: keep the model as simple as possible. Do not add extra death terms.

G. Tests
Add tests or diagnostic scripts that verify:
1. p_mis(C) is monotone increasing and bounded by p_mis_base + p_mis_doxo_max.
2. p_mis(0) = p_mis_base.
3. Direct death is exactly zero in doxorubicin_nullisomy mode.
4. Increasing dose increases expected missegregated chromosome copies per division.
5. For fixed per-copy p_mis, higher chromosome-count states missegregate more total copies on average.
6. Nullisomy risk is lower for high ploidy at fixed absolute number of lost copies, but total nullisomy risk as a function of per-copy p_mis can still increase because high-ploidy cells missegregate more copies.
7. Existing oxygen-model tests / behavior are unchanged outside the new mode.
