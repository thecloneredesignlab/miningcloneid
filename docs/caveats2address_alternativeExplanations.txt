5. For in vitro, distinguishing “rare WGD+ cells were already present” from “rare WGD+ cells arose during the experiment” is lower value for the main conclusion. The important observation is that under oxygen deprivation, the system permits expansion of a high-ploidy/WGD-like subpopulation and later reshapes downward. Whether the first high-ploidy cells were pre-existing or newly generated is secondary unless we claim that hypoxia directly induces WGD. So I would avoid saying “hypoxia generates WGD” unless directly shown. 
For in vivo, the same logic does not hold. If nominal 4N tumors actually come from rare 2N contaminants, that directly threatens the lineage interpretation. So the
  MEDICC2 ancestry test is much more important there.

6. A key comparison is:

  - 2N vs 4N growth in control/normoxic conditions: tests constitutive ploidy-associated growth cost.
  - 2N vs 4N growth under hypoxia/anoxia: tests whether any cost becomes oxygen-dependent.
  - interaction: growth_rate ~ ploidy * oxygen_condition.

  If 4N grows slower than 2N even in control, that supports a baseline high-ploidy cost independent of oxygen. If 4N only falls behind under low oxygen, that supports
  oxygen-dependent high-ploidy cost. If growth rates are similar but ploidy still reshapes, then CIN/WGD/survival dynamics become more central.
