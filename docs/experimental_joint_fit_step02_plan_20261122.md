## 3. Account for shared count and classification errors

Use the archived conditional observation model as primary. Write the count and death contribution for paired records as the product of the within-passage AR(1) count likelihood and a beta-binomial likelihood for dead objects conditional on the observed count and the classifier denominator. The count measures corrected visible objects. The death readout measures dead objects among eligible segmented objects and is modeled on its own denominator. A derived viable proxy such as total count times one minus the dead fraction has no separate score.

Let `L` represent live objects and `B_H`, `B_M` the two visible death-related components. The predicted total is `L + B_H + B_M` on the registered count scale. The classification model uses the underlying odds `(B_H + q B_M) / (L + (1-q) B_M)`, a fitted log-odds offset, the fitted overdispersion, and a shared loading on the same-harvest log-count residual. Preserve the archived bounds on the main model. The shared loading measures an association under the observation model. It cannot establish which imaging fields or masks were reused, and the offset and death visibility can trade off with mechanism estimates.

Refit two prespecified alternative shared-error settings on the same observation mask. First fix the shared loading to zero for all harvests. Then allow the original loading on the main chain while fixing it to zero on the four A7K harvests. Refit the other model parameters in both settings. Report per-assay residuals and the shifts in `p_misseg`, `buffer_beta`, `k_o_mis`, and `mu_hp`, along with the classification, visibility, and dispersion bounds. The archived fit gives a loading of about -0.779 and places the classification offset and visibility fractions at bounds. Treat those as observation-model diagnostics. If raw field-level provenance becomes available, record the matching masks and eligible objects. A field-level joint or conditional likelihood requires a separate observation-contract check before use.
