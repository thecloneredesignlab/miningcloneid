% ANALYTICAL ATTRACTOR SOURCE
%   revised/iteration1/data/Figures/Figure4/fixed_o2_analysis/data/fixed_o2_dominant_ploidy_201grid.tsv
% The table contains 500 seeds x 201 fixed-O2 values = 100,500 analytical
% dominant-attractor evaluations. O2 spans 0--5 percent in increments of
% 0.025 percentage points. No model refitting was performed.
%
% COMPLETE AUC SOURCE
%   revised/iteration1/data/Figures/Figure4/parameter_auc_by_o2.tsv
% This file contains 18 parameters x 201 O2 values = 3,618 AUC rows.
%
% CLASS-COUNT SOURCE
%   revised/iteration1/data/Figures/Figure4/fixed_o2_analysis/data/ploidy_class_counts_by_o2.tsv
% Positive class: dominant_mean_ploidy >= 2.
% Negative class: dominant_mean_ploidy < 2.
% Both classes were present at every reported O2 value.
%
% AUC CALCULATION
% For one O2 value and one parameter, let R_i be the average rank of the
% transformed parameter value, n_+ the number of positive-class fits, and n_-
% the number of negative-class fits. Then:
%   raw AUC =
%     [sum_(i:y_i=1) R_i - n_+(n_+ + 1)/2] / (n_+ n_-).
% This equals P(X_+ > X_-) + 0.5 P(X_+ = X_-).
% Strictly positive parameters were log10 transformed where configured.
% Because the transformation is monotone, it does not change rank-based AUC.
% Discriminative magnitude = max(raw AUC, 1 - raw AUC).
% raw AUC > 0.5 means higher parameter values are associated with
% dominant_mean_ploidy >= 2; raw AUC < 0.5 means higher values are associated
% with dominant_mean_ploidy < 2.
%
% LEADING-INTERVAL RULE
% At each O2 value, the parameter with the largest discriminative AUC was
% selected; exact ties were resolved by the prespecified Figure 4B parameter
% order. Adjacent 0.025-spaced O2 values were collapsed only when both the
% leading parameter and direction were unchanged. The AUC range reports the
% minimum and maximum discriminative AUC inside that contiguous interval.
%
% LANDMARK ROWS
% Landmark rows include every numerical parameter value explicitly discussed
% in the Results plus the previously reported intermediate/high-O2 comparators.
% The complete 3,618-row table remains the exhaustive source.
%
% CLUSTER SOURCES
%   /Users/4482173/Documents/GitHub/soft_coupling/oxygen/results/analysis/best_fit_parameter_feature/02_parameter_landscape_clustering/pooled_invivo_invitro/full_data_in_vivo_clustring/Tables/pooled_invivo_invitro_initial_vs_best_tsne_best_clusters_cluster_summary.csv
%   revised/iteration1/data/Figures/Figure4/figure4d_cluster_prior_interval_summary_all18.tsv
%   revised/iteration1/data/Figures/Figure4/figure4d_cluster_difference_ranking_all18.tsv
% The canonical in vivo t-SNE cluster summary supplies k, cluster sizes, and
% average silhouette. The 18 x 3 interval table supplies the plotted
% prior-referenced parameter summaries. The ranking table was generated from
% those 500 endpoints by the combined Figure 4B plotting workflow (the
% retained script filename predates the A--C panel merge).
%
% CLUSTER-SEPARATION CALCULATION
% For each parameter, eta-squared was calculated on prior-referenced
% transformed positions as between-cluster sum of squares divided by total
% sum of squares. The maximum pairwise difference is the largest absolute
% difference between cluster means on that same scale. These measures rank
% descriptive separation inside clusters constructed from the same fitted
% ensemble; they are not independent hypothesis tests.
%
% GENERATING CODE
%   revised/iteration1/Code/Figures/data_Figure4.R
%   revised/iteration1/Code/Figures/draw_Figure4.R
%
% PORTABLE MACHINE-READABLE TABLE
%   revised/iteration1/manuscript/tables/data/supp_invivo_continuous_o2_auc_values.tsv
%
% INTERPRETIVE LIMIT
% These AUCs are descriptive single-parameter separation measures inside the
% fitted-solution ensemble. They are not p values, causal effects, independent
% prediction accuracy, or multivariable parameter-importance estimates.
