Note on the current asymmetric daughter-construction rule

The current implementation introduces the intended gain–loss asymmetry, but it does so using a deterministic high-risk approximation rather than a neutral expectation over possible missegregation outcomes. Specifically, the affected chromosomes are selected by prioritizing low-copy chromosomes, which makes loss-side daughters systematically more likely to acquire biologically severe events such as complete chromosome loss. As a result, the transition kernel is not an unbiased approximation of a generic missegregation process; rather, it is a pessimistic approximation biased toward the most deleterious daughter allocations.

This is not necessarily inappropriate for a first prototype, because it enforces the desired qualitative asymmetry and exposes the biological consequence of chromosome loss more explicitly than the previous symmetric rule. However, it also means that death may still be overestimated, albeit for a different reason than before. In other words, the model has moved from a symmetric over-penalization of both daughters to a deterministic overemphasis on the most loss-vulnerable outcomes. If future fits continue to show excessive dead-cell accumulation or insufficient live-cell expansion, this daughter-construction rule should be revisited first. A more balanced next step would be to replace the current deterministic low-copy-first selection with either a stochastic allocation scheme or an expected-kernel approximation that preserves gain–loss asymmetry without always privileging the most catastrophic loss events.
