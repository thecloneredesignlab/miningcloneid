# Resolution-aware culture task policy

This isolated release changes task scheduling, evidence bookkeeping and reporting after partial results were observed. It does not change the production numerical model, objective, data, domain, map, single-fit algorithms, optimizer controls, meshes or per-fit budgets. The original seven-point scientific implementation stays immutable.

Same-vector score/component agreement remains 1e-8. Baseline scheduling uses cumulative gain strictly greater than 0.001 from a completed checked anchor. Independent A/B witnesses remain within 0.001 of the actual minimum. A vector-specific checked representative within 1e-4 may support local/final-repeat stopping. Fine profile rises at most 0.002 receive a conservative interpretation flag; restart discrepancies remain visible.

An endpoint representative is never relabeled as the lowest checkpoint. Native Sbplx limits, overall limits and completed directional checks remain separate. Free mapping verifies feasibility without creating a new optimization or independent origin. Old flags and current old-policy gates are preserved beside derived policy results.

The policy uses the existing coherent TSV state, flock, submission-intent/receipt reconciliation, attempt caps, paired reservations and allocation ledger. Anchors are immutable evidence directories referenced by events in atomic state generations. A small record update never moves an anchor by itself. A completed reference intervention explicitly consumes its shared reserve round.

Validation and later mapping/endpoint evidence share a six-core-hour sub-allowance within the original non-fit cap. The cumulative study ceiling remains 4000 allocated core-hours, non-fit 120, origins 36, fitting locals 70, and shared rounds two. Closed rounds are never recreated. Every allocation uses red/xxlarge and no requeue; there is no application concurrency throttle.

Migration first proves numerical and policy evidence, then acquires the existing study lock, preserves state and original gate records, and stops only receipt-selected dispatch controllers. Valid fitting allocations keep their pinned numerical release. A new controller is submitted only after predecessor closure is authoritative. Renewals wait for the predecessor to close before scientific dispatch.

The controller closes scientific dispatch after all submitted valid work and selected diagnostics close. Final accounting, the separately manifested static report and verified collection follow after the controller exits. The known immutable report-writer Boolean defect does not need to be executed to manufacture a failure; any already existing failure remains preserved. The static writer performs no model propagation or optimization.

All outputs use English, R/Python/shell/C++, native RDS and typed TSV. No Java, JavaScript or JSON dependencies or files are used. No tumor fitting, extra points, domain expansion, extra reserve round, new aggregate budget, commit or push is included.

The quality-branch maintenance release completes an existing reserve rule: a near-minimum local candidate from a missing baseline family, with incomplete local evidence, receives priority for a bounded same-origin local audit before another global origin is considered. Every attempt still consumes the original shared local cap. A worse basin outside the recovery band is not polished merely to chase its score. Thresholds and single-fit numerical algorithms are unchanged.

Prior policy-evidence receipts can be reused only when their entire old release remains pinned and evidence.R, evidence.sh and controls.tsv are byte-identical. The compatibility table itself is included in the new immutable manifest. An upgrade preserves the existing anchor, state, attempts and round markers, and uses the same one-writer controller handover.
