# Multi-warmup visualization

These files consume materialized TSV/CSV tables only.

## File registry

- `render_multi_warmup_seed_plan_figures.R`: paired and single-side 18D UMAP figures.
- `render_multi_warmup_landscape_figures.R`: landscape cluster and subcluster figures.
- `render_multi_warmup_collected_figures.R`: objective, DEoptim count, parameter,
  basin-distance, and heatmap figures from collection tables.
- `render_multi_warmup_report_figures.R`: the complete figure set embedded by the
  multi-warmup HTML report.
- `render_warm_up_joint_figures.R`: joint initial/best embeddings, curve-class
  composition/enrichment, curve-class embeddings, and fixed-O2 curve panels.
