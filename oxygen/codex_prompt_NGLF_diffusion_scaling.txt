
TASK
----
Refactor the current oxygen model from a positive GLF (generalized logistic function)
into a biologically grounded NGLF (negative generalized logistic function) with
tumor-size coupling and oxygen-diffusion scaling.

This change should preserve the current MAP / DEoptim fitting pipeline as much as possible,
while replacing the current burden-to-O2 relationship with a monotone decreasing,
size-aware oxygen model.

SCIENTIFIC GOAL
---------------
The current GLF oxygen model is too phenomenological and can produce biologically
undesirable behavior (e.g. oxygen increasing with tumor burden, or oxygen staying
near cap for too long).

We want to replace it with a more mechanistically interpretable model in which:

1. oxygen decreases monotonically with tumor burden
2. the driving variable is not raw tumor cell count alone, but an effective tumor size
3. the decrease is motivated by diffusion limitation / increasing transport distance
4. the model remains simple enough to fit robustly

The desired result is a NGLF-based oxygen curve that behaves like:

    small tumor  -> oxygen near cap
    larger tumor -> oxygen declines
    very large tumor -> oxygen approaches low asymptote

This should serve as a stable baseline oxygen model and be less degenerate than the current CBOF implementation.

MODELING REQUIREMENTS
---------------------
We want the oxygen model to depend on an effective tumor-size variable, not just directly on N.

Assume:
    tumor volume ~ N / rho
    tumor radius ~ (N / rho)^(1/3)

Then define a size-coupled oxygen covariate such as:

    x_size = ((N + eps) / N_anchor)^(1/3)

or on log scale:

    xi_size = (1/3) * [log10(N + eps) - log10(N_anchor + eps)]

Use this xi_size as the input to the NGLF to approximate diffusion limitation.

DESIRED NGLF FORM
-----------------
Preferred form:

    O2_target(N) = O2_min + (O2_cap - O2_min) / (1 + exp(rate * (xi_size - xi0)))^(1 / v)

Definitions:
    O2_cap   = upper asymptote (existing o2_cap_pct)
    O2_min   = lower asymptote (reuse existing lower clamp if present)
    rate     = positive slope magnitude (existing o2_rate)
    v        = asymmetry parameter (existing o2_shape_v)
    xi_size  = tumor-size covariate
    xi0      = anchor determined by o2_anchor_N and o2_init_pct

O2 must be monotone decreasing with N and remain bounded.

ANCHORING REQUIREMENT
---------------------
Preserve the existing anchor parameters:

    o2_init_pct
    o2_anchor_N

The curve must satisfy approximately:

    O2_target(N_anchor) = o2_init_pct

Solve the intercept so the curve passes through this anchor point.
