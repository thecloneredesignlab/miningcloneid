TASK FOR CODEX: Add a minimal hypoxia-linked high-ploidy death term to the O2_CBOF_MAP model, and align code + Methods text

Context
-------
This repository contains an oxygen-coupled ploidy dynamics model for in vivo tumors.
The current model already includes:
1. Oxygen-dependent proliferation rate λ(O2)
2. Oxygen-dependent missegregation probability p_mis(O2)
3. Ploidy-buffering survival after missegregation
4. O2 dynamics via the CBOF (composite burden-driven oxygen feedback with angiogenesis window)
5. Population update with crowding and optional treatment multiplier

Current problem
---------------
The current model can often make the long-term ploidy trend go in the correct direction, but terminal ploidy distributions still do not fit well.
A likely structural reason is that the model currently has:
- growth penalty for high ploidy under low oxygen
but does NOT yet include
- explicit death penalty for high ploidy under low oxygen.

Biological intent
-----------------
Please add an explicit death process linked to O2 and ploidy:

High ploidy cells should be penalized under low oxygen in TWO ways:
1. lower effective proliferation / slower growth
2. higher death

This is intended to be biologically consistent with:
- high ploidy can be more tolerant of a single missegregation event (buffering)
- but under sustained hypoxic stress, high ploidy should have reduced fitness due to metabolic burden
- this should be expressed as both lower birth and higher death

Important design requirements
-----------------------------
1. Keep the existing ploidy-buffering survival term inside the missegregation kernel unchanged.
2. Keep the current CBOF O2 target / lag dynamics unchanged.
3. Add the NEW death term only as a minimal extension.
4. Do NOT introduce many new free parameters.
5. Prefer a single new death-strength parameter, plus reuse existing O2/ploidy quantities where possible.
6. The death term should be active mainly for ploidy above 2N and when oxygen is below a threshold.
7. The implementation should be consistent across:
   - C++ model backend
   - R parameter parsing / parameter table
   - visualization scripts if needed
   - Methods text in TEX

Current model details relevant for implementation
-------------------------------------------------
The current effective proliferation in C++ already has a ploidy/O2 damping form inside the generator builder.
The current code uses a quantity like:
    d = max(0, N/N_unit - 2)
This means:
- no penalty at or below 2N
- increasing penalty above 2N

That same notion should be reused for the death term.

Requested mathematical form
---------------------------
Please implement a minimal additive death rate:
    mu_eff(N, O2) = mu_hp * d * H(O2)

where
    d = max(0, N / N_unit - 2)
and
    H(O2) = max(0, o2_ref_pct - O2)

Alternative equivalent forms are acceptable if numerically safer, but keep the logic:
- zero or near-zero at 2N
- larger above 2N
- larger under lower oxygen
- should not create negative populations or numerical instability

Suggested first implementation:
    mu_eff = mu_hp * d * max(0, o2_ref_pct - O2_use)

with
    mu_hp >= 0

Please use ONLY ONE new parameter initially:
    mu_hp

Do not add a separate baseline death unless absolutely necessary.

How the generator should change
-------------------------------
The current generator is effectively birth-driven with column diagonals set by proliferation.
Please update the C++ generator construction so that death appears as an additional diagonal loss term.

Conceptually:
- existing birth/misseg/WGD terms should stay as they are, still scaled by lam_N
- add a death-only loss term on the diagonal
- the diagonal should now reflect both proliferation outflow and death outflow

So if current diagonal logic is something like:
    diag += -lam_N
it should become something like:
    diag += -(lam_N + mu_N)
where mu_N is the new death rate for that state under the current oxygen.

Important:
- Do not mistakenly multiply death into offspring production.
- Death must only reduce mass from the current state.
- Do not alter the meaning of p_mis or WGD transitions.

Requested model interpretation in Methods
-----------------------------------------
Please align the text with this interpretation:

- Ploidy buffering in the missegregation kernel affects post-event viability of daughter lineages after a missegregation event.
- Separately, sustained hypoxic stress imposes an ecological fitness penalty on high-ploidy states.
- This ecological penalty is represented by:
    1. reduced effective proliferation
    2. increased death for high-ploidy states under low oxygen

This distinction is important and should be explicit.
