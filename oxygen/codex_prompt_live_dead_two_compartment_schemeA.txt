TASK FOR CODEX: Upgrade the current death-enabled ploidy model to a live/dead two-compartment observation-consistent model

Context
-------
This repository currently contains an oxygen-coupled ploidy evolution model for in vivo tumors.
The model already includes:
1. oxygen-dependent proliferation
2. oxygen-dependent missegregation
3. ploidy-buffering survival after missegregation
4. an explicit high-ploidy / low-oxygen death term
5. burden fitting and terminal single-cell ploidy fitting

Current conceptual problem
--------------------------
There is an observation-model mismatch between the two data modalities:

A) Tumor burden / tumor volume observations
These are lesion-scale measurements and reflect not only viable cells, but also recently dead cells,
cell debris, edema, and other residual volume contributions. Therefore, burden should NOT be treated
as an immediate readout of viable-cell count only.

B) Single-cell ploidy observations
These come from single-cell sequencing after QC filtering, and therefore primarily represent viable cells.
So terminal ploidy observations should be matched to the LIVE-cell ploidy distribution only.

Therefore, a single-compartment model in which death immediately removes cells from the burden state
is observation-inconsistent.

Scientific goal
---------------
Please upgrade the current death-enabled model to a minimal two-compartment live/dead formulation:

- live cells drive ploidy evolution
- death moves mass from live to dead
- dead cells do not divide, missegregate, or undergo WGD
- burden observations are matched to live + dead volume contribution
- terminal ploidy observations are matched to live-cell ploidy composition only

This is the preferred implementation (Scheme A).

Design requirements
-------------------
1. Keep the existing live-cell ploidy evolution logic as intact as possible.
2. Keep the existing oxygen model unchanged.
3. Keep the current high-ploidy / low-oxygen death formula unchanged if possible.
4. Add the smallest reasonable number of new parameters.
5. Make the observation model consistent with the biology of the two data modalities.
6. Preserve the existing MAP / DEoptim fitting pipeline as much as possible.

Minimal mathematical structure
------------------------------
For each ploidy state j, define:

    X_live_j(t)   = viable cells in state j
    X_dead_j(t)   = dead / non-viable residual compartment associated with state j

Live dynamics:
    d/dt X_live = birth/misseg/WGD inflow - birth outflow - death outflow

Dead dynamics:
    d/dt X_dead_j = mu_j * X_live_j - k_clear * X_dead_j

where:
    mu_j = current death term already implemented in the code
    k_clear >= 0 is a new clearance / decay rate for dead-cell residual volume

Interpretation:
- death does NOT instantly remove volume from the lesion
- dead cells contribute to tumor burden temporarily
- dead cells are cleared with rate k_clear

Observation model requirements
------------------------------
1. Burden / tumor-volume fitting:
   burden should be computed from BOTH live and dead compartments

Preferred form:
    V_pred(t) = sum_j [ v_live_j * X_live_j(t) ] + omega_dead * sum_j [ v_dead_j * X_dead_j(t) ]

Minimal acceptable simplification:
    - reuse current per-cell volume mapping for live cells
    - let dead cells contribute the same per-cell volume initially
    - fix omega_dead = 1 unless a different constant is already easier to implement

So the minimum viable implementation can be:
    V_pred(t) = sum_j v_j * (X_live_j + X_dead_j)

2. Terminal ploidy fitting:
   terminal ploidy probabilities must be computed from LIVE cells only

Use:
    pi_live_j(T) = X_live_j(T) / sum_k X_live_k(T)

Then continue to use the existing ploidy observation model / mixture model against pi_live_j only.

New parameter(s)
----------------
Add only ONE new parameter initially:

    k_clear

This is the clearance / decay rate of dead-cell residual mass.

Please do NOT add multiple extra observation parameters unless strictly necessary.
If possible:
- keep omega_dead fixed at 1
- keep dead-cell volume contribution equal to live-cell volume contribution

That way the only new dynamic parameter is k_clear.

Implementation requirements

1. C++ backend
--------------
Please modify the main simulation code so that the state includes both live and dead compartments.

Preferred structure:
- if current live state dimension is D, upgraded state dimension becomes 2D
- first D entries = live states
- second D entries = dead states

Live block:
- keep current generator / evolution for live states
- current death term should leave the live diagonal as loss

Dead block:
- add inflow from live death into the corresponding dead state
- dead states should have only diagonal decay / clearance with rate k_clear
- dead states should not produce offspring
- dead states should not undergo missegregation or WGD

Conceptually:
    live_j --(mu_j)--> dead_j --(k_clear)--> removed

Please implement this cleanly in the state-transition / generator logic.
