# Figure 4B eFAST results

Generated by `oxygen/code/O2_supply_demand_MAP/analysis/eFAST/run_efast.sh`
using the independent in-vivo fitted parameter bounds. See the code README
for input provenance, distributions, output definitions and run settings.

The runner now targets five phase repetitions at N=129,257,513, retaining the
original R1/R2 designs and adding R3–R5. The actual repetition count is recorded
in `convergence.tsv`; existing two-phase tables remain historical until the
extended run completes. The separate 500-endpoint neighborhood protocol and
outputs are in [neighborhood10pct](neighborhood10pct/README.md).

The combined figure `figures/efast_four_panel.pdf` has two main panels: A shows
first-order indices (S1) and B shows total-effect indices (ST), with ploidy and
growth aligned within each panel. It includes only the 14 parameters sampled by
eFAST. Rows use the iteration5 Figure 4B High O2, Low O2 and O2-independent
classification as one annotation. A third annotation classifies the eFAST S1
or ST curve by the same oxygen-window, global-peak and BH-significance rule;
this eFAST classification controls the row grouping and order in its panel.
The two output heatmaps remain aligned: classification uses dominant mean
ploidy only, and growth follows the resulting ploidy-based row order. Ploidy
and growth have separate white-to-deep-purple color scales and horizontal
colorbars. The oxygen axis is base-10 symmetric-log with a 0.025% linear
threshold so 0% oxygen can be shown. Black dashed vertical lines at 1% and 3%
oxygen mark the low-window upper boundary and the high-window lower boundary,
respectively.
The copied classification, ranking, process and palette tables are stored
beside these results; `efast_o2_sensitivity_classification.tsv`
contains the new classifications and supporting statistics; and
`figure_redraw_manifest.tsv` records their hashes and the exact data-driven
color limits. Individual first-order and total-effect heatmaps are also in
`figures/`.
The accompanying Figure 4B correlation panel supplies direction. Numerical
source tables are `indices.tsv` and `convergence.tsv`; design and raw operator
evaluations are retained under `runs/`. `parameter_band_summary.tsv` and
`mechanism_band_summary.tsv` aggregate the high-resolution indices over
0–1% and 3–5% oxygen. `mechanism_band_replicates.tsv` gives the same
group means for each phase repeat. `interpretation.md` summarizes the
low- versus high-oxygen mechanism comparison after the full run.
`spectral_gap_qc.tsv` quantifies near-degenerate leading eigenvalues.
