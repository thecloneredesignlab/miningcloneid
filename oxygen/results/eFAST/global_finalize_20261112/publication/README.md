# Figures for the final sensitivity report

Use this directory for the final figure package. Original HPC exports remain unchanged for SHA256 provenance. The strongest-pair and method-comparison curve figures were redrawn from the same saved repeated indices to separate parameter titles from oxygen-band labels and place the comparison legend outside the data panels. No model or sensitivity estimator was rerun. All other figures are unchanged copies.

Five-repeat shading means min-max, not a calibrated confidence interval. S1/ST/S2 have no effect direction. The retained Figure 4B correlation panel supplies direction; C annotations alone do not. P display groups and primary groups in descriptive process summaries are mapped in ../process_group_membership.tsv. Existing conditional response surfaces and their sources are in ../response_surfaces.
