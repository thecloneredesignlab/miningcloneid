# 复用的全域条件响应面

这六对响应面直接复用既有计算，没有重算模型。响应面不依赖Sobol的N，因此可用于解释当前N131072分析，但保留原始full_N4096来源，不改称N131072模型采样结果。

每张图展示固定氧条件下两参数变化时的倍性、增长率及参考点非加性对比。其余参数固定为seed25参考值；显示氧点为0、0.5、2.5和5%。完整敏感性分析仍使用201个氧点。

先读坐标上的参数及尺度，再读色条输出或非加性对比。相同颜色的等值线表示不同参数组合能产生相似输出；若要讨论补偿，必须沿等值线说明两参数如何共同变化，以及固定的背景和氧点。非加性对比的正负相对于所标参考点定义，不是Sobol S2的正负，也不是普遍的生物学协同或拮抗。

本次覆盖lam_max与p_misseg、p_mis_base、O2_crit、mu_hp的四对，以及buffer_smax与buffer_beta、p_mis_base与buffer_smax两对。没有响应面的强S2参数对仍只能讨论交互大小，不能据此补写方向。更高阶交互和TII不在本轮范围。
